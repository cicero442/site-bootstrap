Documentação do Projeto: Bootstrap

Entenda os conceitos do framework utilizado no desenvolvimento deste site

O que é Bootstrap?

O Bootstrap é o framework front-end mais popular do mundo, criado originalmente pelo Twitter. Ele fornece uma estrutura completa com CSS, HTML e JavaScript pré-estilizados e prontos para uso.

Ele é utilizado no desenvolvimento web para acelerar a criação de interfaces modernas, bonitas e totalmente acessíveis sem a necessidade de escrever CSS do zero.

Para que serve?

O Bootstrap ajuda a resolver diversos problemas clássicos do desenvolvimento web:

  • Incompatibilidade de navegadores: Garante visual uniforme no Chrome, Firefox, Safari, Edge, etc.
  • Inexistência de padronização: Oferece um sistema visual consistente de botões, cores e tipografia.
  • Lentidão no desenvolvimento: Elimina a necessidade de criar layouts do zero através de classes utilitárias.

Sistema de Grid

O Sistema de Grid do Bootstrap divide a tela em um layout flexível de 12 colunas. Ele é construído sobre o modelo Flexbox e utiliza classes fundamentais:

  • .container: Limita a largura máxima do conteúdo e centraliza a página horizontalmente.
  • .row: Cria uma linha horizontal para agrupar as colunas (impede vazamentos laterais).
  • .col: Cria colunas que dividem o espaço igualmente de forma automática.
  • .col-md-*: Define o número de colunas ocupadas em telas médias (≥768px, como tablets).
  • .col-lg-*: Define o número de colunas ocupadas em telas grandes (≥992px, como notebooks).
Exemplo Visual do Grid em Ação:
col-12 col-md-6 col-lg-4
col-12 col-md-6 col-lg-4
col-12 col-md-12 col-lg-4
Código Utilizado:
<div class="row">
  <div class="col-12 col-md-6 col-lg-4">Coluna 1</div>
  <div class="col-12 col-md-6 col-lg-4">Coluna 2</div>
  <div class="col-12 col-md-12 col-lg-4">Coluna 3</div>
</div>

Responsividade

Design Responsivo é a técnica de fazer com que uma página web se adapte automaticamente ao tamanho da tela do dispositivo em que está sendo exibida, mantendo a usabilidade sem a necessidade de barras de rolagem horizontais.

O Bootstrap facilita a criação desse tipo de layout fornecendo pontos de interrupção (breakpoints):

📱 Celulares
< 576px (col-12)

Exibe os elementos empilhados em 1 coluna ocupando toda a largura.

📱 Tablets
≥ 768px (col-md-6)

Reorganiza a interface em 2 colunas para melhor aproveitamento.

💻 Notebooks
≥ 992px (col-lg-4)

Apresenta o conteúdo em 3 ou mais colunas lado a lado.

🖥️ Monitores
≥ 1200px (col-xl)

Expande margens e espaçamentos mantendo o alinhamento central.

Componentes Utilizados no Projeto

Abaixo estão 6 componentes do Bootstrap que foram utilizados na construção deste site:

1. Navbar

Barra de navegação superior responsiva com suporte a logotipos, links e menu "hambúrguer" colapsável para dispositivos móveis.

2. Cards

Containeres flexíveis que organizam informações visuais com imagens, títulos, textos e botões (usado nos pacotes de viagem).

3. Alert (Alertas)

Caixas de mensagens destacadas e interativas, utilizadas no topo das páginas para divulgar promoções e avisos importantes.

4. Modal

Janela flutuante interativa que sobrepõe a página, utilizada na página de destinos para abrir o formulário de reserva.

5. Buttons (Botões)

Classes de estilo aplicadas a botões (ex: btn-primary, btn-outline-light) para ações interativas padronizadas.

6. Accordion

Painel sanfonado expansível utilizado na seção de "Dúvidas Frequentes" para economizar espaço de tela.
